# BALANCE НББ — суулгах заавар

Нэг программд олон компанийн нягтлан бодох бүртгэлийг хөтөлнө. Өгөгдөл нь таны Google Sheet-д, программ нь Apps Script вэб апп хэлбэрээр ажиллана.

## 1. Суулгах (10 минут)

1. Google Drive дээр шинэ Google Sheet үүсгээд **BALANCE НББ** гэж нэрлэнэ.
2. **Өргөтгөл (Extensions) → Apps Script** цэсийг нээнэ.
3. `Code.gs` файлын доторх кодыг бүгдийг нь устгаад, энэ багцын `Code.gs`-ийг буулгана.
4. **+ → HTML** дарж файлын нэрийг яг **`Index`** гэж өгнө. Доторх кодыг нь `Index.html`-ээр солино.
5. **Project Settings (⚙)** хэсэгт:
   - Time zone-ийг **(GMT+08:00) Ulaanbaatar** болгоно.
   - Эсвэл “Show appsscript.json” сонголтыг асааж, `appsscript.json`-ийг буулгана.
6. Хадгалаад (Ctrl+S) Google Sheet-ээ дахин ачаална (refresh).
7. Sheet-ийн дээд хэсэгт **BALANCE НББ → 1. Анхны тохиргоо хийх** цэс гарч ирнэ.
   - Google эрх асуухад зөвшөөрнө.
   - Эхний компанийн нэр болон **admin** хэрэглэгчийн нууц үгийг (8-аас дээш тэмдэгт) оруулна.
   - Ингэхэд хүснэгтүүд, жишиг дансны төлөвлөгөө автоматаар үүснэ.
8. Apps Script дээр **Deploy → New deployment → Web app** сонгож дараах тохиргоог хийнэ:
   - Execute as: **Me**
   - Who has access: **Anyone**
   - Программ өөрийн нэвтрэлт, эрхийн системтэй тул ажилтнууд Google данс шаардахгүй нэвтэрнэ.
9. Гарсан **Web app URL**-ийг нээгээд `admin` болон өөрийн нууц үгээр нэвтэрнэ.

> ⚠️ **Google Sheet-ийг ажилтнуудтай БҮҮ хуваалцаарай.** Ажилтнууд зөвхөн вэб аппаар орно. Sheet дээр шууд засвар хийвэл давхар бичилт, аудит лог, тайлант үеийн хамгаалалтыг тойрч гарна.

**Код шинэчлэх бол:** Deploy → Manage deployments → ✎ → Version: **New version** → Deploy. Ингэхэд URL өөрчлөгдөхгүй.

## 2. Эхний тохиргоо (вэб апп дотор)

1. **Тохиргоо → Компани:**
   - Бусад компаниа нэмнэ (жишээ нь Рокет фарм ДСС, Мед бокс).
   - НӨАТ төлөгч эсэхийг тэмдэглэнэ. НӨАТ төлөгч бол загвар гүйлгээнд НӨАТ автоматаар тусгагдана.
2. **Тохиргоо → Чиглэл:** бизнесийн чиглэлүүдээ (POS, LOAN, PC, MED…) бүртгэнэ. Орлогын тайланг чиглэл бүрээр гаргах боломжтой болно.
3. **Тохиргоо → Татвар:** НӨАТ, ААНОАТ-ын хувь хэмжээ, босгыг шалгана. Эдгээр нь хуулиар өөрчлөгддөг тул тохиргоогоор удирдана.
4. **Тохиргоо → Хэрэглэгчид:** ажилтан бүрт эрх (Нягтлан / Менежер / Захирал / Харах) болон хандах компанийг олгоно. Хэрэглэгч анх нэвтрэхдээ нууц үгээ солино.
5. **Дансны төлөвлөгөө:** жишиг төлөвлөгөөг өөрийн хэрэгцээнд тааруулна.
   - **Дэд төрөл** нь тайланд хэрэглэгддэг тул зөв сонгох хэрэгтэй. Жишээ нь Мөнгө (касс, харилцах), Авлага, Өглөг, НӨАТ, Борлуулсан бүтээгдэхүүний өртөг.
   - Банкны харилцах данс бүрийг тусад нь нэмэхэд тохиромжтой (1121 Хаан банк, 1122 Голомт г.м.).
6. **Эхний үлдэгдэл:** нэг гүйлгээгээр оруулна.
   - Огноо нь эхлэх өдрийн өмнөх өдөр байна (жишээ нь 2025-12-31).
   - Бүх дансны үлдэгдлийг дебет/кредит талд нь оруулна.
   - Авлага, өглөгийг харилцагч тус бүрээр мөр болгон задална.
   - Эсвэл **Импорт** хэсгээр Excel-ээс оруулна.

## 3. Ажиллах зарчим

| Зарчим | Хэрэгжилт |
|---|---|
| Давхар бичилт | Дебет ≠ Кредит бол батлахгүй. Бүлэг дансанд бичихгүй. Авлага/өглөгийн дансанд харилцагч заавал байна. |
| Мөнгөн дүн | Мөнгөөр (₮×100) бүхэл тоогоор хадгална. Float ашиглахгүй. |
| Засвар | Батлагдсан гүйлгээг устгах/засахгүй — **Буцаалт хийх** товчоор урвуу гүйлгээ бичнэ. Зөвхөн ноорог засагдана. |
| Бүхэл бичилт (transaction) | Гүйлгээний мөрүүдийг эхэлж бичээд толгойг дараа нь баталгаажуулна. Тайлан зөвхөн толгойтойгоо таарсан мөрийг тооцдог тул дундуур тасарсан бичилт тайланд орохгүй. Бичих үйлдлүүд түгжээ (LockService) ашиглана. |
| Тайлант үе | Хаагдсан сард гүйлгээ бичихгүй. Жилийн хаалт нь орлого, зардлын дансыг хааж ашгийг хуримтлагдсан ашигт шилжүүлнэ. Цуцалж болно. |
| Аудит | Нэвтрэлт, бүх бичилт, засвар, хаалт Audit хүснэгтэд бүртгэгдэнэ. |
| Эрх | Админ, Захирал, Менежер, Нягтлан, Харах — эрхийн хүснэгт нь Тохиргоо → Хэрэглэгчид хэсэгт байна. |

### Тайлангууд

- Гүйлгээ баланс (бүлгийн дүнтэй, чиглэлээр шүүх боломжтой)
- Дансны хуулга / ерөнхий дэвтэр
- Харилцагчийн хуулга
- Санхүүгийн байдлын тайлан (2 огнооны харьцуулалттай)
- Орлогын дэлгэрэнгүй тайлан (чиглэлээр задлах боломжтой)
- Мөнгөн гүйлгээний тайлан (шууд арга)
- Өмчийн өөрчлөлтийн тайлан
- Авлага, өглөгийн насжилт (FIFO)
- НӨАТ-ын сарын тооцоо, ААНОАТ-ын урьдчилсан тооцоо

Бүх тайланг CSV-ээр татах, Excel рүү хуулах, хэвлэх/PDF болгох боломжтой.

## 4. Sheet доторх хүснэгтүүд

`Companies`, `Users`, `Accounts`, `Partners`, `Segments`, `Periods`, `Entries` (гүйлгээний толгой), `Lines` (дебет/кредит мөрүүд, зөвхөн нэмэгдэнэ), `Settings`, `Audit`.

## 5. Хязгаарлалт ба дараагийн шат

- Google Sheet нь ойролцоогоор хэдэн арван мянган гүйлгээний мөр хүртэл хурдан ажиллана.
- Үүнээс их болох эсвэл олон хэрэглэгч зэрэг ажиллах үед PostgreSQL + вэб backend руу шилжүүлэх нь зүйтэй. Өгөгдлийн бүтэц нь шууд хөрвүүлэх боломжтойгоор хийгдсэн.
- **Дараагийн шат:**
  - Бараа материал (жигнэсэн дундаж өртөг)
  - Үндсэн хөрөнгө ба элэгдэл
  - Цалин (ХХОАТ, НДШ — тохиргоогоор)
  - Банкны хуулга импорт
  - e-barimt / etax / e-balance-ийн тайлангийн маягтууд
